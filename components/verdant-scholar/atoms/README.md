# Verdant Scholar atoms

Foundational controls for the editorial Stitch language: tonal badges, gradient buttons, quiet icon buttons, pill search
fields, understated progress indicators, and animated atmosphere containers (Subarctic Dawn, Deep Forest Canopy hero
variant, Misty Marshland). Each atom now also has a dedicated Storybook story alongside the gallery overview so states,
controls, and simple interactions can be reviewed in isolation.
