# components/ui

Shared low-level UI primitives and micro-components used across the app.

- shadcn-style base controls such as button, input, card, dialog, dropdown, and tooltip.
- `collapsible.tsx`: shadcn-compatible Radix collapsible primitives used for tree-style disclosure UIs.
- `keyboard-hint.tsx`: Reusable styled keyboard keycap hints for shortcuts/help text.
