FIRESTORE COMPOSITE INDEXES REQUIRED

=================================================================================
IMPORTANT: You don't need to create these manually upfront!
=================================================================================

When you encounter an "index required" error, Firebase provides a direct link
to create the specific index. Simply:
1. Click the URL in the error message
2. Firebase Console opens with the index pre-configured
3. Click "Create Index"
4. Wait for the index to build (2-5 minutes)

=================================================================================
REQUIRED INDEXES
=================================================================================

Index 1: STACKS BY GROUP (for /learn page)
------------------------------------------
Collection ID: stacks
Fields:
  - groupId (Ascending)
  - order (Ascending)
Query scope: Collection

Index 2: SPECIES BY STACK (for flashcards and quizzes)
-------------------------------------------------------
Collection ID: species
Fields:
  - stackId (Ascending)
  - order (Ascending)
Query scope: Collection

Index 3: GROUPS BY USER (for editor's manage page)
---------------------------------------------------
Collection ID: groups
Fields:
  - createdBy (Ascending)
  - order (Ascending)
Query scope: Collection

Index 4: STACKS BY GROUP AND USER (for editor's stack management)
------------------------------------------------------------------
Collection ID: stacks
Fields:
  - groupId (Ascending)
  - createdBy (Ascending)
  - order (Ascending)
Query scope: Collection

=================================================================================
HOW TO CREATE INDEXES MANUALLY (if needed)
=================================================================================

1. Go to Firebase Console > Firestore Database > Indexes tab
2. Click "Create Index"
3. Select the collection name (e.g., "stacks")
4. Click "Add field" and select the first field (e.g., "groupId")
5. Set to "Ascending"
6. Click "Add field" again for the next field (e.g., "order")
7. Set to "Ascending"
8. Query scope: Collection
9. Click "Create"
10. Wait for index to build (status will change from "Building" to "Enabled")
